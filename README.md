# 움짤 공방

틀을 고르고 칸마다 사진을 넣으면 반짝이·꽃잎·둥실둥실 효과가 들어간 움짤 GIF를 만들어 주는 정적 웹페이지입니다.

- 틀: 폰 목업, 폰 두 대, 폴라로이드 세 장, 프로필 카드
- 사진 넣기: 칸 클릭, 파일 끌어놓기, 붙여넣기 / 드래그로 위치, 휠·슬라이더로 확대
- GIF 인코딩은 브라우저 안에서 직접 처리 (외부 라이브러리·서버 없음)

`index.html` 하나로 동작합니다. GitHub Pages에 올리거나 파일을 바로 열면 됩니다.

## 새 틀 추가하기
`index.html`의 `TEMPLATES` 배열에 항목을 추가합니다.
- `slots`: 사진 칸 목록 (`cx`, `cy`, `w`, `h`, `r`, `rot`, `shape`)
- `texts`: 문구 입력 칸
- `render(ctx, p, env)`: `p`는 0→1 한 바퀴 진행도. `env.slot(id)`는 현재 좌표 원점에 해당 칸을 그립니다.
